# motor-finance-complaints-sql

## Project overview

This is a personal SQL learning project built using Microsoft SQL Server and SQL Server Management Studio (SSMS).
The project models a fictional motor finance complaints database. It will be developed over time to practice database design, SQL querying, data analysis and MI reporting.

## Current progress

* Created relational database structure
* Created Customers, Vehicles, FinanceAgreements, Complaints tables
* Added primary keys
* Added foreign key relationships
* Added fictional sample data across all four tables
* Set up the project with Git and GitHub for version control

## Next steps

Begin querying and analysing the data using SQL, including:

* Filtering and sorting complaint data
* Aggregate functions and GROUP BY
* JOINs across related tables
* Complaint volume and outcome analysis
* SLA performance analysis
* MI-Style reporting
